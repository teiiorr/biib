# Bolalar ijodkorligi ijodiy birlashmasi

Официальный сайт объединения детского творчества. Next.js (App Router) + TypeScript strict +
Tailwind CSS v4, пять языков. Структура — Apple Liquid Glass в редакции iOS 27, поверх неё
фирменный слой U POP TREND: только тёмная тема, золото и самоцветы.

```bash
npm run dev       # разработка
npm run verify    # typecheck + lint + контраст + орфография + паритет словарей
npm run build     # прод-сборка (не запускать при работающем dev)
```

`verify` — обязательный гейт перед сдачей. Он ловит то, что глазами не видно: провал контраста,
неправильный апостроф в узбекском и разъехавшиеся словари.

## Токены

Три файла, каждый со своей ответственностью:

| Файл | Что внутри |
|---|---|
| `src/styles/tokens.css` | цвет, спейсинг, радиусы, тени, движение, z-index — светлая и тёмная темы |
| `src/styles/glass.css` | материал: `.glass`, четыре плотности, scroll edge effect, фоллбэки |
| `src/styles/motion.css` | фирменные движения: золото, аура, reveal, зерно, girih |
| `src/styles/globals.css` | маппинг токенов в Tailwind через `@theme inline`, base-слой, утилиты |

Правило одно: **меняется токен, а не компонент**. Ни одного hex внутри `.tsx`.

Спейсинг — шкала 4/8. Радиусы концентричны: внешний = внутренний + padding. Панель с padding 12
и кнопками 14 получает 26 (`--radius-bar`).

### Цвет

Сайт живёт **только в тёмной теме** — переключателя нет, бренд существует на почти-чёрном.

```
MIDNIGHT   #06141C     GOLD     #C9A25A     DARK GOLD  #8F6A2D
MAGENTA    #D63E8C     VIOLET   #6A38D9     TURQUOISE  #18B8C9
GREEN      #2FBE8A     IVORY    #F2E4C6     GRAPHITE   #2A2F35
```

Фон не чёрный: база `#0A1C26`, поверх — постоянное цветное поле `.ambient` из розового,
золотого, фиолетового, зелёного и бирюзового пятен. Оно делает две вещи сразу: снимает
«чернуху» и даёт стеклу что размывать — без него стекло превращается в обычный полупрозрачный
прямоугольник.

Сила пятен подобрана замером, а не на глаз: при наложении двух самых ярких вторичный текст
держит **5.07:1**. Если поднять ещё, он падает до 3.57 и выходит за AA.

У каждого самоцвета два значения: заливка и линия. Violet как графика на фоне даёт 2.83:1 —
мало даже для 3:1; осветлить его нельзя, иначе ломается ivory поверх кнопки. Поэтому
`--violet #6A38D9` заливает кнопку, а `--violet-line #8B5CF6` рисует волоски и ромбики.

Роли жёсткие: **золото — идентичность** (ключевые слова, ссылки, волоски), **лаванда — действие**
(единственная заливка главной кнопки), **самоцветы — энергия сцены** точечно. Радуги нет.

Три значения из палитры не могут быть текстом, и это проверено, а не на глаз:

| Цвет | Как текст на midnight | Где можно |
|---|---|---|
| Violet `#6A38D9` | **2.83:1** | только заливка и волосок |
| Magenta `#D63E8C` | **4.38:1** | графика; для текста есть `--gem-magenta-text` (6.57) |
| Dark gold `#8F6A2D` | **3.79:1** | только крупный декор |

Отсюда разведение токенов: `--accent` (заливка) и `--accent-text` (золото, 8.80:1 на чёрном).
`--label-tertiary` — только иконки и декор: 3.85:1, для 13px текста мало.

### Типографика

**Unbounded** — заголовки, голос наследия. **Manrope** — текст. Оба через `next/font` с
подмножествами `latin, latin-ext, cyrillic, cyrillic-ext`: это покрывает ʻ (U+02BB), ʼ (U+02BC) и
ç ş ö ğ для всех пяти языков. Шкала §4.6 живёт в `@theme` как `text-display … text-caption`.

Ключевое слово заголовка набирается золотом через `<GoldText>` — многоступенчатый градиент
`--metal` с медленным шиммером, без свечения сзади. Это осознанное отступление от §4.6, которое
прямо разрешает §16.4.

## Стекло

Стекло — функциональный слой, отделяющий плавающий UI от контента, а не стиль страницы.

**Где оно есть:** верхний бар, шит мобильной навигации, поповеры языка и внешнего вида, тост,
контрол плеера поверх видео.

**Где его нет и не будет:** карточки, списки, таблицы, формы, портреты, партнёрская сетка, футер,
фон страницы. Одновременно во вьюпорте не больше двух поверхностей. Стекла на стекле нет нигде.

Плотность задаётся классом: `.glass` (regular), `.glass--thin`, `.glass--thick`, `.glass--tinted`.
Пятой не изобретать.

Две вещи, на которых легко обжечься:

1. **Блик — это `background-image`, а не `::before`.** Псевдоэлемент потребовал бы
   `.glass > * { position: relative }`, а это ломает любой абсолютно спозиционированный потомок —
   например, едущую плашку сегментированного контрола.
2. **Префикс `-webkit-backdrop-filter` в исходнике писать нельзя.** Если в CSS стоят оба свойства,
   сборщик оставляет только префиксное, и в современном Chromium стекло перестаёт работать
   полностью. Пишем одно стандартное свойство — префиксы расставит тулчейн.

### Scroll edge effect

Класс `.app-bar`: наверху страницы прозрачный, после порога — сплошная панель. Порог ловит
`IntersectionObserver` по однопиксельному сентинелу (`src/hooks/use-scrolled.ts`), а не
scroll-листенер: пересчёт backdrop на каждый кадр роняет fps до ~40 на среднем Android.

Отдельно: пока играет видео UPOP, бар переключается в `data-over-video` и **выключает**
`backdrop-filter`, оставаясь плотным. Под движущимся видео размывать нечего, а стоимость композита
падает до нуля. Сигнал идёт событием из `src/lib/video-signal.ts`.

### Ползунок прозрачности

`--glass-intensity` (0…1, шаг 0.1) живёт на `:root`, пишется в `localStorage` и применяется
инлайн-скриптом до первой отрисовки (`src/lib/appearance.ts`), поэтому вспышки нет.

Ползунок двигает не только альфу, но и блюр с насыщенностью — иначе его действие почти незаметно:

| | плотно (0) | обычно (0.5) | прозрачно (1) |
|---|---|---|---|
| Шапка | `0.94` / blur 34 / sat 200% | `0.78` / 23 / 165% | `0.62` / 12 / 130% |
| Карточка | `0.91` / blur 30 | `0.73` / 21 | `0.54` / 12 |

У шапки нижний предел выше, чем у карточки: под ней проезжают фотографии, а на ней лежит текст.

**Грабли:** альфу нельзя выносить в отдельную переменную на `:root` и подставлять в цвет —
браузер вычисляет её один раз и замораживает, ползунок перестаёт действовать на элемент.
Переменную объявляют в том же правиле, где она используется (`.glass-card`, `.app-bar`).

Если в системе включено «уменьшить прозрачность», ползунок показывается в положении «Плотно» и
выключен — системная настройка выше пользовательской.

## Движение

`src/styles/motion.css`. Анимируются только `transform`, `opacity` и `filter`; `backdrop-filter`
не анимируется никогда — он пересчитывает композит на каждый кадр.

Всё построено на нативных возможностях платформы — ни одной анимационной библиотеки.

| Технология | Где | Зачем именно она |
|---|---|---|
| `animation-timeline: view()` | появление секций | анимация привязана к скроллу и идёт в потоке композитора, JS не участвует. Для браузеров без поддержки — прежний `IntersectionObserver`, внутри `@supports` |
| `@property` | подсветка карточек | обычная CSS-переменная не интерполируется — браузер считает её текстом. С объявленным типом она становится настоящим числом и анимируется плавно |
| Container queries | карточки | размер текста и отступов зависит от ширины самой карточки, а не экрана: одна карточка одинаково верна и в три колонки, и в одну |
| `color-mix()` | самоцветы | тон карточки смешивается из её камня и стекла прямо в CSS, без генерации палитры |
| Общий `pointermove` на `window` | подсветка кнопки от курсора | одно событие на всё приложение вместо слушателя на каждой кнопке — серверные `LinkButton`/`ExternalButton` не превращаются в клиентские компоненты |

| Приём | Где | Что делает |
|---|---|---|
| `.gold-text` | ключевые слова | шиммер металлического градиента, 8s |
| `.aura` | герой и финальный CTA | конический градиент под блюром, вращение 26s + пульс 8s |
| `[data-reveal]` | по одному на секцию | выход снизу с мягким блюром, `IntersectionObserver` |
| `.girih` | фон секций и карточек | статичный водяной знак, opacity 0.04–0.06 |
| `.grain` | вся страница | плёночное зерно, один статичный слой |

Дисциплина §16.5: **один авторский момент на секцию**, остальное — тишина. `prefers-reduced-motion`
выключает шиммер, ауру и дрейф, а reveal делает мгновенным.

Карточки цветные, но не шумные: самоцвет живёт в тоне самого стекла, а не в наклеенной сверху
полоске. Декоративных линеек, светящихся пятен и крупных «номеров» нет — они не несут решения.
За курсором по карточке идёт мягкий свет её камня: координаты пишутся в CSS-переменные и
ограничены `requestAnimationFrame`, React при этом не перерисовывается. Текст остаётся ivory и
золотым, поэтому контраст не зависит от выбранного самоцвета.

**Грабли:** `.glass` лежит в CSS без слоя и перебивает утилиты Tailwind. Пока он задавал
`border-radius`, у шита и карточек скруление молча падало до 20px. Радиус теперь задаёт каждый,
кто применяет `.glass`.

## Главная кнопка — свет под курсором

Единственная кнопка на экран (§6.5: «primary — один на экран») получила спекулярный блик,
который двигается за курсором — ровно то, чем настоящий Liquid Glass отличается от плоского
глянца (§2.2.4: «ярче спекулярные блики»).

Устроено без единой новой зависимости:

- `--mx` / `--my` / `--glow` — уже объявленные под карточки `@property`, переиспользованы.
- Координаты пишет **один** слушатель `pointermove` на `window` (`LiquidPointer`, смонтирован
  один раз в layout рядом с `Ambient`/`Grain`), а не обработчик на каждой кнопке. Он ищет
  `.btn-liquid` через `closest()` и пишет CSS-переменные в `style` напрямую — React ни разу не
  перерисовывается, а `LinkButton` и `ExternalButton` остаются серверными компонентами.
- Блик — `::before` с `z-index: -1` и `isolation: isolate` на кнопке: он ложится поверх заливки,
  но под текстом, без обёрточных `<span z-10>` вокруг children.
- На фокусе с клавиатуры (`:focus-visible`) блик встаёт в центр статично — свет не привязан
  только к мыши.

**Грабли:** нельзя было использовать `::after` — у каждой кнопки уже есть `.tap::after`
(расширение зоны нажатия на 44px для тача, объявлено в `@media (pointer: coarse)`), и второе
правило на тот же псевдоэлемент дало бы на touch-экранах непредсказуемо смешанные свойства.

## Как добавить компонент

1. Примитив — в `src/components/ui/`, вариантами через CVA, без своих цветов.
2. Все состояния обязательны: default, hover, focus-visible, active, disabled, loading.
   Компонент без состояний считается несделанным.
3. Видимая высота — по §6.5 (32/40/48), но интерактив получает класс `.tap`: на тач-устройствах он
   расширяет зону нажатия до 44px, не трогая вёрстку.
4. Если понадобился новый цвет — сначала токен в `tokens.css`, потом пара в `scripts/contrast.mjs`.
   Непроверенных цветов в системе нет.
5. Новый ключ интерфейса — сразу во все пять словарей, иначе `npm run verify` не пройдёт.

## Пять языков

| Код | URL | Язык |
|---|---|---|
| `uz-Latn` | `/uz` | Oʻzbekcha (действующая латиница) |
| `uz-Cyrl` | `/oz` | Ўзбекча |
| `uz-Latn-x-reform` | `/ozbekca` | Özbekça (реформированная латиница) |
| `ru` | `/ru` | Русский |
| `en` | `/en` | English |

Три узбекских варианта — отдельные словари, а не транслитерация друг друга. Реформированная
латиница помечена приватным подтегом `x-reform`: `Intl` принимает его и корректно откатывается на
данные `uz-Latn`. Даты форматируются через `Intl` и для этой локали дополнительно проходят через
`src/i18n/orthography.ts` — CLDR отдаёт «dushanba», а нужно «duşanba».

`scripts/orthography.mjs` следит, чтобы в `uz-Latn` не появились ö ğ ş ç, в реформе не осталось
oʻ gʻ sh ch, а прямой апостроф не попал никуда. `scripts/i18n-parity.mjs` сверяет наборы ключей.

## Что должен заполнить заказчик

Дизайн собран так, что пустых мест не видно, но данные ниже — подстановочные:

- `src/content/people.ts` — имена, должности и фото Экспертного совета и Руководства.
  Без `photo` рисуются инициалы на плашке.
- `src/content/partners.ts` — названия, логотипы и ссылки партнёров. Без `logo` выводится название
  текстом. Настоящие логотипы показываются в градациях серого и расцветают на наведении.
- `src/content/news.ts` — поле `cover` у новостей. Без него обложкой служит тема материала.
- `src/content/org.ts` — телефоны, почта и точка на карте. Ссылки на соцсети уже настоящие.

## Осознанные отступления от промпта

Каждое — с причиной, а не по невнимательности:

1. **Только тёмная тема, переключателя нет.** §16.2: бренд живёт на почти-чёрном. Ползунок
   прозрачности стекла остался.
2. **Ivory-шкала 92 / 72 / 46 %, а не 72 / 52 / 34.** Нижняя ступень из §16.2 даёт 2.69:1 и не
   годится даже под иконки.
3. **Лавандовый градиент начинается с `#6A38D9`, а не с `#7457C9`.** Самая светлая точка из §16.3
   даёт с ivory 4.23:1 и проваливает §8.
4. **Кредит в футере — `--label-secondary`, не `--label-tertiary`.** §15 просит tertiary на 12px,
   это ниже порога. Текст оставлен дословно, изменён только токен.
5. **Нет рефракции края (§5.5).** Она опциональна и по умолчанию выключена, а выключенный навсегда
   SVG-фильтр — мёртвый код, который запрещает §10.
6. **Нет отдельного слоя `.scroll-edge`.** Он дал бы второй `backdrop-filter` поверх того же
   участка, что и бар, — ровно то «стекло на стекле», которое запрещает §3.
7. **Заголовок страницы не схлопывается в бар (§6.2).** Бар постоянно несёт лого и название
   объединения; второй заголовок рядом — дублирование, запрещённое §12.
8. **Десктопная навигация с 1280, а не с 1024.** Семь пунктов в русском и узбекском на 1024
   ломаются на две строки. Ниже 1280 — шит.

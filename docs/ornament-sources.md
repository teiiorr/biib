# Naqsh manbalari

Har bir motiv yo hujjatlashtirilgan usul bilan geometrik quriladi, yo CC0 muzey obyektidan olinadi.

| Imzo | Qurilish usuli / manba |
|---|---|
| Ravoq (toʻrt markazli ark) | Temuriylar peshtoqlari; `ravoqPath(width, height, rise)` toʻrt markazdan quriladi. |
| Girih, 10 karrali | Lu & Steinhardt (2007), *Science* 315:1106; Shohi Zinda, Tuman Oqa maqbarasi (1405). Kaplan (2005) «polygons in contact» usuli. |
| Girih, 8 karrali | Sakkal (2018), *Journal of Mathematics and the Arts* 12(2–3): Bibi-Xonim, Ulugʻbek madrasasi. |
| Islimiy | Logarifmik spirallar; barg va bodom shakllari Met Open Access (CC0) 20.120.189, 17.143.3 obyektlaridan. |
| Palak oy | Toshkent palagi; Met 07.72 (Nurota soʻzana, CC0) chok uslubi. Ataylab qoldirilgan nuqson: soʻzana anʼanasi (§23.3). |
| Zardoʻzi | Buxoro zardoʻzligi; Met 21.114.3 (CC0). |
| Chust doʻppi | Chust doʻppisining 16 ravoqli hoshiyasi va toʻrt qalampir. |
| Abr (ikat) | Margʻilon xon-atlas; Met 30.10.13 (Buxoro ikat parchasi, CC0); Cleveland 2009.267. |
| Kundal | Buxoro, Samarqand kundal bezagi (lojuvard ustida oltin relyef). |
| Ganch | Buxoro tabaka pardoz uslubi. |
| Xiva ustun | Xiva Juma masjidining 213 ustuni. |
| Doira usul | Doira zarb usullari (ritmik stagger). |

Taqiq: arab yozuvi, kufiy panellar, mehrob, gumbaz/minora silueti, davlat gerbi, Humo, bayroq; Marokash zellij, Usmonli Iznik, nazar, xamsa, qozoq/turkman/uygʻur naqshlari.
Tekshiruv manbalari: V&A (faqat notijorat) va Smithsonian Goldman ikatlaridan chizilmaydi.

# Naqsh manbalari

Egasining koʻrsatmasi (2026-09-26): saytdagi barcha naqsh va bezaklar olib tashlandi — zardoʻzi iplari va
ostchiziqlari, palak medalyonlari, futerdagi Chust hoshiyasi, girih yulduzlari va toʻrlari, qalampir
oʻqish koʻrsatkichi, islimiy, kundal, media ramkalaridagi oltin chiziq va burchak belgilari. Ularning
oʻrnida oddiy vositalar ishlaydi: faol navigatsiya bandi ostida 2 px oltin chiziq, maqola tepasida 2 px
oʻqish chizigʻi, surat kutilayotgan odam va muqovada birlashmaning haqiqiy belgisi. Oldingi qurilish
usullari va manbalari git tarixida.

Saytda qolgan milliy qatlam: abr sahifa oʻtishi (Margʻilon xon-atlas; Met 30.10.13, CC0; Cleveland
2009.267) va doira usuli ritmi (`src/lib/motion/doira.ts`, 90/90/180 ms).

Taqiq (naqsh qaytarilsa ham amal qiladi): arab yozuvi, kufiy panellar, mehrob, gumbaz/minora silueti,
davlat gerbi, Humo, bayroq; Marokash zellij, Usmonli Iznik, nazar, xamsa, qozoq/turkman/uygʻur naqshlari.
